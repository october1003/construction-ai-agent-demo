# 房建项目AI文档自动化Agent 实践Demo
## 项目简介
本人从事房建工程项目管理工作，日常高频编写施工日志、安全专项检查报告、整改回复、工程联系单等标准化文档。
基于 OpenClaw + DeepSeek/豆包大模型 搭建轻量化AI自动化Agent，实现工程类标准文档一键生成、格式统一、内容合规，替代大量重复人工编写工作，提升项目办公与文档整理效率。

## 核心能力
1. 按照建筑行业标准模板，自动生成每日施工日志、安全检查周报、整改回复文案；
2. 输入现场概况、施工部位、进度节点，Agent自主补全专业术语与规范表述；
3. 统一文档排版结构，省去人工调格式、凑内容、查规范的重复工作量；
4. 支持本地离线调试、多轮上下文优化，适配房建项目日常办公场景。

## 技术栈
- AI Agent框架：OpenClaw
- 底层大模型：DeepSeek、豆包系列
- 应用场景：房建工程项目文档自动化、办公文案辅助生成

## 仓库内容说明
本仓库为个人学习实践Demo，存放Agent调试记录、生成文档样例、简易调用脚本，仅用于小米MIMO开发者入驻资质佐证与个人技术沉淀，无商用用途。
